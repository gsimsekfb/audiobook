# Audio Per Chapter

Create one MP3 and matching SRT file for each `Abstract` or numbered chapter
heading found in a text-based PDF.

## Setup

From the project folder:

```powershell
python -m pip install pypdf edge-tts
```

## Create chapter audio

```powershell
python 'audio per chapter/create_chapter_audio.py' `
    'bitcoin-whitepaper-audio/bitcoin-whitepaper.pdf' `
    'audio per chapter/bitcoin-whitepaper'
```

The command writes `<chapter>.txt`, `<chapter>.mp3` in
the output folder. It uses `en-US-EricNeural` by default; pass
`--voice VOICE_NAME` to select another Edge TTS voice. Use `--pages N` to
process only the first N PDF pages.

## Verify with the first two pages

```powershell
python 'audio per chapter/create_chapter_audio.py' `
    'bitcoin-whitepaper-audio/bitcoin-whitepaper.pdf' `
    'audio per chapter/bitcoin-first-two-pages' `
    --pages 2 `
    --max-chapters 3
```

The output should contain these three MP3 files:

```text
abstract.mp3
introduction.mp3
transactions.mp3
```

The extra limit is needed here because the PDF places the next chapter heading
at the bottom of page 2.

## Create the remaining chapters

Skip the three chapters already generated by the verification command:

```powershell
python 'audio per chapter/create_chapter_audio.py' `
    'bitcoin-whitepaper-audio/bitcoin-whitepaper.pdf' `
    'audio per chapter/bitcoin-remaining-chapters' `
    --skip-chapters 3
```

Edge TTS requires an internet connection.
