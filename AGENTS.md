# Project rules

- Always prefer shortest answer possible for simple questions, ideally one sentence.

- Never change original text from source !!!

- Always tell me what you will do first. Do not start any work without my approval.

- Whenever modifying any frontend file under `docs/` (`app.js`, `config.js`, `engines/*.js`, `style.css`), always increment the `?v=N` cache-busting query parameter in `docs/index.html` and `docs/app.js`.
